# ESP32-S2 & WS2812B LED 바 하드웨어 연결 가이드

`kitt-eye`의 임베디드 펌웨어(`mcu-rust`)는 **ESP32-S2**와 **WS2812B NeoPixel 8구 LED 바**를 연결하여 AI 에이전트의 상태를 시각화합니다. 이 문서는 보드별 핀아웃, 배선도, 전원 연결 시 주의사항 및 문제 해결법을 안내합니다.

---

## 1. 준비물

| 부품 | 수량 | 설명 |
|---|---|---|
| **ESP32-S2 개발 보드** | 1개 | Wemos S2 Mini, ESP32-S2-DevKitM-1, NodeMCU-S2 등 |
| **WS2812B LED 바** | 1개 | 8구(8-LED) 스틱 또는 스트립 형태 (5V 동작) |
| **점퍼선** | 3가닥 | 암-암(Female-Female) 또는 암-수(Female-Male) 점퍼 와이어 |
| **USB-C 케이블** | 1개 | PC 연결 및 전원 공급용 (데이터 통신 가능 케이블) |

---

## 2. 배선도 (Wiring Table)

WS2812B LED 바는 전원선 2개와 데이터 신호선 1개, 총 **3개의 선만 연결**하면 동작합니다.

| ESP32-S2 핀 | WS2812B LED 바 핀 | 신호 종류 | 설명 |
|---|---|---|---|
| **VBUS** (또는 **5V**) | **VCC** (또는 **5V**) | 전원 (+) | 5V 전원 공급 (USB 5V 직결) |
| **GND** | **GND** | 전원 (-) | 공통 그라운드 접지 |
| **GPIO6** (IO6) | **DIN** (또는 **DI**) | SPI MOSI 데이터 | 고속 WS2812B 제어 데이터 신호선 |

> ⚠️ **주의사항**:
> 1. **신호 방향 (DIN vs DOUT)**: LED 바에는 신호 입력단인 **DIN(또는 DI, IN)** 과 확장용 출력단인 **DOUT(또는 DO, OUT)** 이 있습니다. 반드시 **DIN**에 ESP32의 GPIO6을 연결해야 합니다. DOUT에 연결하면 LED가 켜지지 않습니다.
> 2. **GPIO4 (SCK)**: 펌웨어 내부에서 SPI2 마스터 초기화용으로 GPIO4를 SCK로 지정하고 있으나, WS2812는 클록선이 필요 없는 1-Wire 비동기 통신이므로 **GPIO4는 물리적으로 배선하지 않고 비워둡니다**.

## 3. 대표 보드별 연결 상세

### 3.1. WEMOS S2 Mini (가장 대중적인 초소형 보드)

S2 Mini 보드의 경우 핀 라벨이 숫자로 직접 표기되어 있어 직관적입니다.

```text
               [ USB-C 포트 ]
          ┌───────────────────────┐
   VBUS ──┤ [VBUS]           [1]  ├── 
          │ [3V3]            [2]  ├── 
          │ [16]             [3]  ├── 
          │ [18]             [4]  ├── (내부 SCK 예약 - 미연결)
          │ [33]             [5]  ├── 
          │ [35]            *[6]* ├── ─── [DIN] WS2812B
          │ [37]             [7]  ├── 
          │ [39]             [8]  ├── 
          │ [40]             [9]  ├── 
          │ [17]             [10] ├── 
          │ [21]             [11] ├── 
          │ [34]             [12] ├── 
          │ [36]             [13] ├── 
          │ [38]             [14] ├── 
    GND ──┤ [GND]           [RST] ├── 
          └───────────────────────┘
                     S2 Mini
```

- **VBUS 핀**: 보드 좌측 최상단 `VBUS` 핀을 LED 바의 `5V/VCC`에 연결합니다.
- **GND 핀**: 보드 좌측 최하단 `GND` 핀을 LED 바의 `GND`에 연결합니다.
- **GPIO6 핀**: 보드 우측 6번째 핀 `6`을 LED 바의 `DIN`에 연결합니다.

---

### 3.2. ESP32-S2-Saola-1 / DevKitC / NodeMCU-S2

표준 개발 보드의 경우 핀 헤더에 `5V`, `G`, `IO6`으로 각인되어 있습니다.

```text
+-----------------------+                    +--------------------+
|   ESP32-S2 Dev Board  |                    |  WS2812B 8-LED Bar |
|                       |                    |                    |
|             5V / VBUS | -----------------> | 5V / VCC           |
|                   GND | -----------------> | GND                |
|           GPIO6 / IO6 | -----------------> | DIN (Data In)      |
|                       |                    |                    |
| (GPIO4는 연결 안 함)   |                    | DOUT (미사용)      |
+-----------------------+                    +--------------------+
```

## 4. 작동 원리 (왜 SPI GPIO6인가?)

WS2812B는 800kHz 주파수에서 펄스 폭(Duty cycle)으로 0과 1을 판별하는 매우 정밀한 타이밍 제약(~1.25 µs 단위)을 가집니다. 일반적인 GPIO 소프트웨어 비트뱅잉(bit-banging) 방식은 인터럽트나 Wi-Fi 처리 중 타이밍이 어긋나 LED 깜빡임이나 오동작이 발생하기 쉽습니다.

`kitt-eye`는 ESP32-S2의 **하드웨어 SPI2(FSPI)** 컨트롤러를 3.2 MHz로 구동하여, 1개의 WS2812 비트를 4개의 SPI 비트 패턴으로 변환(Prerendered SPI Encoding)하여 출력합니다:
- WS2812 `0` bit → SPI `0b1000`
- WS2812 `1` bit → SPI `0b1110`

따라서 **GPIO6(SPI2 MOSI)** 핀에서 CPU 개입 없이 하드웨어 레벨의 완벽한 타이밍으로 신호가 방출되므로 흔들림 없이 안정적으로 LED가 동작합니다.

## 5. 플래시 다운로드 모드 (Bootloader) 진입 방법

ESP32-S2는 Native USB를 사용하므로, 펌웨어를 처음 플래시할 때 수동으로 ROM 부트로더(다운로드 모드)에 진입해야 할 수 있습니다:

1. 보드의 **`0`번(또는 `BOOT`) 버튼**을 누르고 유지합니다.
2. 누른 상태에서 **`RST`(또는 `RESET`) 버튼**을 짧게 딸깍 누릅니다.
3. 누르고 있던 **`0`번(또는 `BOOT`) 버튼**을 손에서 뗍니다.
4. PC에서 시리얼 포트(`/dev/cu.usbmodem*`)가 인식되었는지 확인하고 플래시합니다:
   ```bash
   make flash-mcu
   ```

## 6. 트러블슈팅

### Q1. 첫 번째 LED만 하얗게 켜지고 나머지 LED는 안 켜집니다.
- **원인 1**: 신호선을 `DIN`이 아닌 `DOUT`에 연결했을 가능성이 높습니다. 반대편 단자의 `DIN`으로 옮겨 연결하세요.
- **원인 2**: 전원 공급 부족 또는 그라운드 접촉 불량. 점퍼선이 헐겁지 않은지 확인하세요.

### Q2. 전체 LED에 불이 전혀 들어오지 않습니다.
- 보드의 `VBUS` 핀에 5V가 정상 출력되는지 테스터기나 전원 LED로 확인하세요.
- 일부 개발보드의 경우 `3V3` 핀만 나와 있는 경우가 있습니다. 3.3V 전압으로도 WS2812B가 동작할 수 있으나, 전압 강하가 심할 경우 켜지지 않을 수 있으므로 USB 5V 라인에서 직접 전원을 공급해야 합니다.
- 펌웨어 부팅 상태를 확인하려면 터미널에서 모니터링을 확인하세요:
  ```bash
  cargo espflash monitor
  ```

### Q3. Wi-Fi 연결 전에는 어떤 패턴이 나와야 하나요?
- Wi-Fi에 연결되기 전에는 **무지개 색상 좌우 바운스(Rainbow Bounce)** 애니메이션이 표시됩니다.
- Wi-Fi 및 MQTT 브로커 연결이 완료되면 에이전트의 활성 상태 패턴(기본 `idle`: 느린 레드 왕복)으로 전환됩니다.
